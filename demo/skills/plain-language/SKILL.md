# Plain language

When asked to simplify text:

- Keep sentences under 20 words.
- Prefer common words; explain a necessary technical term the first time it appears.
- Use the active voice.
- Keep the meaning and the language of the original text.

Change the document only through the editor's tools, and only the text the user selected or named.
