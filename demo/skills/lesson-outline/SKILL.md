# Lesson outline

When asked for a lesson outline:

1. Write one sentence with the learning objective, starting with a verb ("Explain…", "Compare…").
2. List exactly three steps, each with a short activity and its duration in minutes.
3. End with one closing question that checks understanding.

Keep the outline in the language of the document content, not the interface language. Insert it into the document with the editor's tools when the user asks to apply it.
